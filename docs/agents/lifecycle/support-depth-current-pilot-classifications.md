## Whole regimes and remaining prerequisites

All cells are governed by the fixed typed adapter boundary in the [current route document](support-depth-codex-pilot-readiness.md).
All five selectors, unattended/interactive/external safety branches and last/id cases remain due.
Initial/resume exec and app-server variants share one operation population and one basis;
no variant can inherit an exec-only no-effect conclusion. BASE and mapped `M` remain due.

- **Typed values:** preserve the production adapter's model, private cwd/add-dir, prompt,
  selector, approval and sandbox validation. Preserve native granular decisions and native
  rejections; do not substitute a policy or enable automatic approval. Explicit ids preserve
  their bytes. The production serializer chooses exact CLI/RPC placement. A global/local
  spelling is not blanket permission to emit that option at another path.
- **Unexposed CLI intent:** deny every caller-supplied raw argv/value, including help/version,
  alternate provider/profile, hooks/trust bypass, feature toggles, listener/remote/auth,
  thread-source, image, worktree, output-schema and all-session switches. Absence and defaults
  remain part of each row. Such a denied-intent proposal is CORE with real rejection/no-effect
  proof still due, not EXCLUDED, NA, debt or removal. The obsolete claim-only `--full-auto`
  remains unresolved until version-bound rejection and wrapper-claim correspondence are proved.
- **Generated configuration:** only the source-owned controlled config and the adapter's
  actual approval/sandbox/reasoning translations are candidates. Arbitrary strings, home,
  overlays or profile/provider/features changes must fail the future isolated guard before
  native invocation. No generic SDK caller restriction is added here. Binding emitted values
  alone does not prove effective native defaults.
- **Mutation:** ADMIN covers actual last-message output, native initialization state and
  bundled artifacts, session persistence and partial effects on failure. Worktree/other output
  intent remains denied; conservative historical ADMIN assignments are retained as proposals.
- **Protocol:** MANAGED covers owned stdio, correlation, interaction delivery, bounded events,
  cancellation and cleanup. CLI transport flags remain denied; app-server's default stdio
  needs native evidence. SESSION covers resume/fork identity and no-match behavior. Internal
  listing adds no public QUERY promise. No CLI RPC SurfaceIdentity is fabricated.

**Unresolved for every affected cell:** effective runtime feature/default semantics, native
provider endpoint/auth intent, native loader and bundled skill behavior, actual adapter child
boundary observations, full allowed/denied guards, packet-specific native execution and
independent adequacy. The [runtime observation](support-depth-codex-runtime-context.md)
establishes only its listed facts. In particular, tool_registry remains unobserved, the native
feature listing forces six values true despite false config, and startup creates files.
Until these prerequisites and individual row approval exist, all207 candidate edges remain
classification_required in the diagnostic. This table does not install or clear any row.
